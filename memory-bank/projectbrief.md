# Project Brief: Langflow

## Project Overview
Langflow is a powerful open-source tool for building and deploying AI-powered agents and workflows. It provides developers with both a visual authoring experience and built-in API and MCP servers that turn every workflow into a tool that can be integrated into applications built on any framework or stack.

## Core Purpose
- **Visual AI Workflow Builder**: Enable developers to create AI workflows through an intuitive visual interface
- **Multi-Modal Integration**: Support all major LLMs, vector databases, and a growing library of AI tools
- **Production-Ready Deployment**: Provide multiple deployment options including API servers and MCP servers
- **Developer-Friendly**: Offer both visual and code-based customization options

## Key Features
- **Visual builder interface** to quickly get started and iterate
- **Source code access** lets you customize any component using Python
- **Interactive playground** to immediately test and refine flows with step-by-step control
- **Multi-agent orchestration** with conversation management and retrieval
- **Deploy as an API** or export as JSON for Python apps
- **Deploy as an MCP server** and turn flows into tools for MCP clients
- **Observability** with LangSmith, LangFuse and other integrations
- **Enterprise-ready** security and scalability

## Target Users
- AI/ML developers building conversational agents
- Data scientists creating AI workflows
- Enterprise teams deploying AI solutions
- Developers integrating AI capabilities into existing applications

## Technical Foundation
- **Backend**: Python-based with FastAPI
- **Frontend**: React/TypeScript with visual flow editor
- **Architecture**: Component-based system with extensible plugin architecture
- **Deployment**: Docker, cloud platforms, local development

## Project Goals
1. Democratize AI workflow creation through visual tools
2. Provide enterprise-grade reliability and scalability
3. Maintain extensibility for custom components and integrations
4. Support multiple deployment patterns (API, MCP, standalone)
5. Foster an active open-source community
